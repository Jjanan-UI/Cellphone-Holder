## 📌 Project Overview
This repository contains the design, engineering drawing, and manufacturing specifications for a minimalist, flat-pattern sheet metal cellphone holder. Designed for simple laser cutting and press-brake bending, this project demonstrates a tool-less, interlocking design that transforms a single flat piece of sheet metal into a functional, stable, and ergonomic desktop stand.

## 📊 Key Specifications
| Parameter | Specification |
| :--- | :--- |
| **Part Type** | Interlocking Folded Sheet Metal Stand |
| **Material** | Cold Rolled Steel (per drawing title block) |
| **Overall Size (Folded)** | Approx. 104.87 mm (W) × 94.34 mm (D) × 100.37 mm (H) |
| **Manufacturing Process** | Laser Cutting → Bending → Finishing (e.g., Powder Coating) |
| **Hardware** | None (Tool-less interlocking slot & tab design) |
| **Bends** | 4 Bends Total: 2 × 90° (UP), 2 × 120° (DOWN), 3 mm Inner Radius |

## 🛠️ Features
*   **Tool-less Assembly:** Features a smart interlocking slot and tab mechanism at the base. The two ends slot together to lock the stand into its 3D form without the need for screws, rivets, or welding.
*   **Ergonomic Design:** The bent geometry creates a 60° viewing angle, ideal for watching videos or video calls.
*   **Device Retention Lip:** The front edge is specifically designed with a two-pronged bent lip (15.00 mm depth) to securely cradle the phone and prevent it from sliding off.
*   **Design for Manufacturing (DFM):** Designed entirely as a 2D flat pattern. The geometry allows for high-yield nesting on a sheet, minimizing material waste. Includes defined bend reliefs to prevent tearing at the stress points.

## 📂 Repository Structure
*   `/cad` - 3D models (SolidWorks/Fusion 360 files) and the flat pattern.
*   `/drawings` - The formal PDF specification sheet (including bend table A-D) and DXF files for laser cutting.
*   `/images` - Renders and reference photos.

## 🚀 Getting Started
1. Review the `Cellphone Holder - For laser Cutting File.dxf` file for laser cutting or CNC punching. 
2. Refer to the `Cellphone Holder Specification.pdf` for exact dimensions and the formal bend table:
    *   **Bend A & B:** 90° UP
    *   **Bend C & D:** 120° DOWN
3. Fabricate the part, ensuring a 3.00 mm inner radius on all bends to match the design intent.
